# Afisaku — Shopee Affiliate Tracker

Web app untuk tracking performa Shopee Affiliate, Meta Ads, dan manajemen keuangan.

## Deploy ke Vercel

1. Upload folder ini ke GitHub
2. Buka vercel.com → Import project dari GitHub
3. Klik Deploy — selesai!

## Tech Stack
- React 18 + Vite
- Firebase Firestore (shared cloud storage)
